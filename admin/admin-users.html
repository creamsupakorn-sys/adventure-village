คุณ ปรียา มงคล

🏢 นิติบุคคล (แอดมิน)

🏠 สำนักงานส่วนกลาง

ฐานข้อมูลสมาชิกและทีมช่าง

ตรวจสอบรายชื่อลูกบ้าน ช่างซ่อมบำรุง และผลประเมินความพึงพอใจ

กรองบทบาท :
ชื่อ-นามสกุล บทบาท บ้านเลขที่ / แผนก เบอร์โทรศัพท์ อีเมล จัดการ
⭐ คะแนนความพึงพอใจเฉลี่ยรวมของหมู่บ้าน ยังไม่มีผลประเมิน
รหัสงาน ปัญหาที่แจ้ง ช่างผู้รับผิดชอบ คะแนน ข้อเสนอแนะจากลูกบ้าน

+ เพิ่มรายชื่อช่าง / สมาชิกใหม่
